# Chip Gallery — Originals (Private)

Place full-resolution chip photos here, then run:

```bash
npm run chips:thumbs
```

| Location | Deployed? | Purpose |
|----------|-----------|---------|
| `source/chip_gallery/originals/` | **No** (gitignored) | Master chip images |
| `public/gallery/chips/thumb/` | **Yes** | Watermarked web thumbnails (~1280px JPEG) |
